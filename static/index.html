Project MayDay

From SQL to live A/B test in one session. Query real data, build a model, and deploy it.

Phase 1

Explore the Data

Query the e-commerce ad database using SQL. Understand users, ads, clicks, and conversions. Look for patterns that might shape your modelling choices.

~45 minutes
Phase 2

Build Your Model

Engineer features and train an ML model. The most interesting decision isn't which algorithm to use — it's what to optimise for.

~75 minutes
Phase 3

Optimise for Production

Your model must serve predictions in real time. Slow models get penalised. Navigate the accuracy–latency tradeoff.

~30 minutes
Phase 4

Deploy & Test Live

Upload your model to the live A/B test. Watch the dashboard as traffic flows through every team's model. Iterate and improve.

~45 minutes
